## 📌 Sobre o Projeto
Este projeto é uma aplicação web para catálogo de filmes em cartaz e reserva de ingressos de cinema. A página foi construída com uma abordagem comparativa, apresentando o mesmo layout e funcionalidades desenvolvidos com duas das principais ferramentas de estilização da atualidade: **Tailwind CSS** e **Bootstrap 5**.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **HTML5:** Estruturação semântica de toda a interface web.
- **Tailwind CSS (via CDN):** Utilizado para a estilização da primeira seção do projeto através de classes utilitárias modernas e responsivas.
- **Bootstrap 5 (via npm/módulo):** Utilizado na segunda seção da página para estilização através de componentes pré-formatados (cards, navbar, formulários e grid system).
- **CSS3 Customizado:** Estilos próprios localizados em `./src/css/style.css` para ajustes visuais específicos.
- **JavaScript ES6:** Manipulação do DOM e lógica de preenchimento dinâmico para os seletores de reserva (`./src/js/script.js`).

---

## 🚀 Funcionalidades da Aplicação

- **Navegação Responsiva:** Barras de navegação adaptáveis para dispositivos móveis e desktops.
- **Catálogo de Filmes em Cartaz:**
  - Cards com imagem do filme, faixa etária, gênero, duração e preços.
  - Efeitos interativos ao passar o mouse (*hover*).
  - Filmes em destaque: *Invocação do Mal 3*, *Homem-Aranha: Um Novo Dia*, *A Odisseia*, *Patrulha Canina*, *Moana* e *Ponto sem Retorno*.
- **Seção de Combos e Aperitivos:** Exibição detalhada de valores para pipocas, bebidas e o *Combo Master*.
- **Formulário de Reserva:** Campo para nome, e-mail e seleção do filme desejado.
